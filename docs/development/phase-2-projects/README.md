# Phase 2 — Project intelligence

Status: not started. Depends on an independently useful literature layer.

## Purpose

Maintain the evolving intellectual state of software/HPC research projects and connect questions, hypotheses, assumptions, decisions, findings, failures, and unresolved observations to literature evidence. Human-authored project descriptions remain authoritative.

## Detailed plan steps

1. **2.1** Review research project management, lab notebooks, scientific knowledge systems, agent memory, and provenance practices.
2. **2.2** Define the project-state model and literature references.
3. **2.3** Ingest human descriptions, repositories/history, issues, notes, and existing metadata.
4. **2.4** Support project-to-literature and literature-to-project reasoning.
5. **2.5** Preserve useful project memory: attempts, failures, anomalies, contradictions, and decision rationale.
6. **2.6** Integrate heterogeneous agents and harnesses across machines.
7. **2.7** Recover known history from a mature project retrospectively.
8. **2.8** Evaluate during an active project prospectively.
9. **2.9** Compare agents using repository-only, raw notes, and Shiroe project state.

## Deliverables and records

Produce the Project Layer Technology and Methods Review, requirements, architecture shortlist, literature integration plan, evaluation results, and phase technical report. Store [planning artifacts](planning/README.md) and [decisions](decisions/README.md) here. See [the original plan](<../sources/Shiroe Development Plan.md>) for full requirements.

## Completion gate

> Multiple agents on different systems can interrogate the same project and reliably recover relevant project history and literature context without receiving the complete project history in their context window.

No phase-specific survey, implementation, or validation has been performed yet.
