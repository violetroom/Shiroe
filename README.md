# Shiroe

Shiroe preserves research state across literature, projects, and experiments, with evidence provenance and shared access across machines and agents.

Start with the [development documentation](docs/development/README.md), [decision ledger](docs/development/DECISIONS.md), and [Phase 0 index](docs/development/phase-0-core/README.md).

The project is currently in Phase 0 planning. No server, client integration, or distributed completion gate has been validated.
